# ADR-008 手续费 fee 与用户金额 amount 分开

- 状态：已定（取代 v0.1 的 price）
- 日期：2026-10-22

## 背景

v0.1 只有一个 `price`，既当 Relay 向供给方收的手续费，又当授权里「单笔金额上限」比较的用户金额。两笔钱的付款方、量级和用途都不同。

## 决定

- `fee`：Relay 向供给方收的手续费，整数，单位分，建单时快照。平台定价范围 ¥1–¥100 每笔（审核策略，不是协议约束）；Relay 自营的沙箱商家 fee=0。
- `amount`：用户在这笔交易里要花的钱，只用于授权金额上限判定，Relay 不收。取值 `"none"`、固定整数分、或 `{"from": "input.<字段>"}`。
- 取自输入字段时，该字段必须是 `integer`、单位分、必填（规则 M-AMT-1/2/3）。所以撮合示例的预算字段叫 `budget_cents`，不是「2 万」这样的文字。

## 后果

- 授权判定和计费互不干扰。
- 供给方要把金额字段改成分，这是一次性的小成本。
