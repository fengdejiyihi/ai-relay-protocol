# ADR-004 HMAC-SHA256 签名，secret 加密存储

- 状态：已定
- 日期：2026-10-22

## 背景

Relay 和供给方之间需要双向认证：防止有人伪造 Relay 请求让产品白干活，也防止有人伪造回调让订单「完成」从而扣费。供给方多是小团队，大概率写过 Stripe Webhook 验签。

## 决定

- 头部 `X-Relay-Signature: t=<unix 秒>,v1=<hex>`，`v1 = HMAC-SHA256(secret, t + "." + 原始请求体)`，与 Stripe 同款。双向使用同一个 secret。
- 时间窗 5 分钟，常量时间比较，必须对原始字节验签。
- 轮换时新旧 secret 并存 24 小时，头部可带多个 `v1`。

## 后果

- 供给方实现验签约 15 行代码，附录 B 有骨架。
